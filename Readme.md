# AI PDF Summarizer

## Overview
This project summarizes the content of PDF documents.
Users can upload a PDF file and receive a clear, readable summary.

## Problem
PDF documents are often long and time-consuming to read.
This project helps extract the key information quickly.

## What This Project Does
- Accepts a PDF file as input
- Extracts and cleans the text
- Splits the text into manageable parts
- Generates a summary for each part
- Combines all summaries into a final result

## How It Works (High Level)
- Text is extracted from the uploaded PDF
- The text is cleaned and split into chunks
- Each chunk is summarized using an AI model
- The summaries are combined and shown to the user

## Tech Used
- Python
- Streamlit
- PDF text extraction
- Text summarization model

## Use Case
- Summarizing reports and documents
- Quick review of long PDFs
- Learning project for document processing with AI

## Status
Working prototype for learning and demonstration purposes.
